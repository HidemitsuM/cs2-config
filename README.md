# CS2 Autoexec Config

Counter-Strike 2 (CS2) 用の最適化されたautoexec設定ファイルです。

## 特徴

- **マウス・エイム設定**: DPI 800向けに調整された感度設定
- **カスタムキーバインド**: 
  - マウスホイール下: ジャンプ
  - マウスホイール上: **C4**
  - マウスサイドボタン: 武器切り替え（前: メイン武器、後: サブ武器）
- **ネットワーク最適化**: Sub-tick対応、低レイテンシ設定
- **パフォーマンス向上**: FPS最大化、視覚ノイズ削減
- **クロスヘア設定**: リコイル時の動作を無効化した固定クロスヘア（黄色）
- **ビューモデル最適化**: 武器モデルの画面占有率を最小化

## インストール方法

1. `autoexec.cfg` を以下のパスに配置:
   - **Steam版**: `<Steamインストール先>\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\`
   - **Linux/Steam Deck**: `~/.steam/steam/steamapps/common/Counter-Strike Global Offensive/game/csgo/cfg/`

2. CS2を起動して、コンソールで以下を実行:
   ```
   exec autoexec
   ```
   ※ `autoexec.cfg` はゲーム起動時に自動的に読み込まれます

3. 設定をリロードするには `F8` キーを押してください

## 主な設定

### マウス・エイム
- **感度**: 0.84 (800 DPI推奨)
- **ズーム感度比**: 0.9
- **m_yaw**: 0.022 (16:9または4:3ブラックバー)

### ネットワーク
- **帯域幅**: 786432
- **バッファティック**: 0 (LAN/完璧な接続用)

### クロスヘア
- **スタイル**: 静的 (リコイル時も固定)
- **色**: デフォルト緑
- **サイズ**: 2.0 / 太さ: 0.5 / ギャップ: 0（密着・シンプルな十字）

### HUD
- **色**: チームカラー (CT=青、T=赤)

### ビューモデル
- **FOV**: 68 (武器を遠ざける)
- **Xオフセット**: 2.5 (右寄せ)
- **Yオフセット**: 0 (ニュートラル)
- **Zオフセット**: -2.0 (下寄せ)

## キーバインド一覧

| キー | アクション |
|------|-----------|
| Space / MWheel Down | ジャンプ |
| MWheel Up | C4装備 |
| Mouse4 (前サイド) | メイン武器 |
| Mouse5 (後サイド) | サブ武器 |
| 1 | メイン武器 |
| 2 | サブ武器 |
| 4 | HEグレネード |
| V | フラッシュバン |
| C | スモーク |
| X | モロトフ/焼夷手榴弾 |
| E | レーダー拡大 (+use連動) |
| N | クロスヘアサイズ切り替え |
| F8 | コンフィグ再読み込み |

## カスタマイズ

感度を変更する場合は、`autoexec.cfg` の以下の行を編集してください:

```cfg
sensitivity "0.84"    // 好みの値に変更
```

4:3ストレッチ解像度を使用している場合は、`m_yaw` を以下に変更:

```cfg
m_yaw "0.0165"
```
